# Academic Scores

A lightweight web application for managing academic scores across semesters, with automatic average calculation and Excel/CSV import and export.

## Features

* Manage scores across semesters
* Add and remove subjects
* Edit scores directly
* Automatically calculate average scores
* Persistent data storage using local storage
* Import `.xlsx`, `.xls`, and `.csv` files
* Export scores to Excel
* Uses SheetJS for spreadsheet processing
